## Running Your Application

- running from an IDE:
    - first import your project.
- running as a packaged application
    - if using spring boot maven or gradle, use `java -jar`
    - also you can run a packaged application with remote debugging support enabled, attaching a debugger to your packaged application.
- using the maven plugin:
    - includes a `run ` goal that can be used to quickly compile and run your application.
      ```shell
        $ mvn spring-boot:run
      ```
