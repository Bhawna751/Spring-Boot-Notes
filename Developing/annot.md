<details>
  <summary>Using the @SpringBootApplication Annotation</summary>

  - @SpringBootApplication can be used to enable three features:
      - @EnableAutoConfiguration: enable spring boot's auto-configuration mechanism
      - @ComponentScan: enable @Component scan on the package where the application is located
      - @SpringBootConfiguration: enable registration of extra beans in the context or the import of additional configuration classes.
</details>
